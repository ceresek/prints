# About

Replacement fastener rings for Garmin 22 mm watch strap,
tested with Garmin Instinct 2 Solar.

# Printing

The prototype was printed in Prusament TPU 95A with 0.2 mm layers
and 8 perimeters, to avoid any infill related distortions. Adding
skirt helped pressurize the nozzle.
