# About

Kids room door sign.
My son asked for one and hand picked the icons :-)

# Design

The design should accept SVG icons with closed line shapes.
Use `inkscape input.svg --batch-process --actions="select-all:all;object-to-path;object-stroke-to-path;path-union;export-filename:output.svg;export-do" to convert other files.

# Printing

I had a prototype printed with PETG but then settled on PLA, both would probably work.
For me, 3 perimeters and 0.2 mm constant layer was fine, plus manual color change
for the icons, obviously. No supports needed.

After printing, rotate the lid and use the gap on the back to get each notch to catch.
The design is somewhat tight, after working it for a bit the wheel should rotate
easily enough but stay in position afterwards.
